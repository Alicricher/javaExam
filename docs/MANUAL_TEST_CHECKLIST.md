# Ручной чеклист: полный флоу (2026-09-01)

Проверка всего пути после этой сессии правок: билингвальность (RU/UZ) бота и админки,
роли/доступ профессоров, PDF-статистика, транслитерация, редактор вопросов теста,
безопасность сервера. Отмечайте `[x]` по ходу, при найденном баге — записывайте прямо
в пункт (что сломалось, на каком шаге).

## Перед началом

- [ ] Два тестовых Telegram-аккаунта (или один, но готовность дважды пройти регистрацию/сброс) — один поставит язык `uz`, другой `ru`.
- [ ] Доступ в админку: `ssh dental` туннель поднят, `http://localhost:8080` открывается.
- [ ] Знать логин/пароль минимум одного `SUPER_ADMIN`-аккаунта.
- [ ] Если будете проверять права профессора — понадобится отдельный `PROFESSOR`-аккаунт, назначенный только на один юнит (создать в шаге 6, если ещё нет).

---

## 1. Бот — регистрация и язык

- [ ] `/start` новому аккаунту → выбор языка (узбекский/русский) первым шагом.
- [ ] Выбрать **узбекский** → все поля регистрации (курс, группа, подгруппа, факультет) на узбекском.
- [ ] Подгруппа — только **A / B / C**, кнопки "D" нет.
- [ ] Завершить регистрацию → главное меню на узбекском ("📚 O'qishni boshlash", "👤 Profil").
- [ ] Профиль → сменить язык на русский → **сразу же** (без /start) нижние кнопки меню перерисовываются на русский ("📚 Начать обучение", "👤 Профиль") — это был отдельный баг, важно перепроверить.
- [ ] Второй тестовый аккаунт: та же регистрация, но сразу выбрать **русский** — все шаги регистрации на русском.

## 2. Бот — выбор раздела и урока (билингвальность контента)

- [ ] "Начать обучение" → список разделов F1/F2/F3 показывается **на языке профиля** (не только F1/F2/F3, а и подпись рядом — "Первый раздел" на ru, "Birinchi bo'lim" на uz).
- [ ] Выбрать F1 → список из 15 уроков, названия на языке профиля.
- [ ] Открыть один и тот же урок (например, урок 1) сначала под uz-аккаунтом, потом под ru-аккаунтом — **текст должен реально отличаться**, а не быть на одном языке в обоих случаях.
- [ ] Кнопка "Назад" из списка уроков возвращает к списку разделов — тоже на правильном языке (не только в первый заход, но и через "назад").

## 3. Бот — прохождение теста

- [ ] Урок → Тест → название теста, число вопросов, время, баллы — на языке профиля.
- [ ] Пройти тест: текст вопроса и варианты ответов — на языке профиля, не переключаются на середине теста, даже если сменить язык в профиле параллельно (это не обязано подхватываться на лету — язык теста фиксируется в момент старта, это ожидаемо).
- [ ] Ответить на все вопросы → результат/баллы показываются.
- [ ] Пройти тот же тест повторно (если разрешены попытки) → номер попытки отображается **корректно** (это был баг ранее — статичный номер).
- [ ] Если тест уже проходили раньше — при повторном заходе показывается уведомление о пересдаче, а не тихо начинается заново.

## 4. Бот — ситуационная задача

- [ ] Урок → Ситуационные задачи → список задач урока.
- [ ] Открыть задачу → текст на языке профиля, есть таймер.
- [ ] Отправить текстовый ответ → дождаться оценки от ИИ.
- [ ] В уведомлении о результате есть **ссылки на источники** ("Manbalar"/"Источники"), не пустые.
- [ ] Язык фидбека ИИ соответствует языку, на котором **сам студент написал ответ** (не языку интерфейса) — это осознанное поведение, не баг.
- [ ] Если у задачи есть фото — оно приходит в боте.

## 5. Бот — теория и таймаут

- [ ] Урок → Теория → категории (книги/пособия/материалы) на языке профиля.
- [ ] Открыть/скачать любой материал — файл приходит.
- [ ] (Опционально, долгий тест) Начать тест и не отвечать до истечения времени — приходит уведомление о таймауте, тест засчитывается как не пройденный вовремя, статистика по группе такого студента не учитывает.

## 6. Админка — вход и язык интерфейса

- [ ] Открыть `http://localhost:8080`, ввести **неверный** пароль → видно понятную ошибку (не "зависшая" страница).
- [ ] Войти с верным паролем.
- [ ] Переключить язык RU/UZ в сайдбаре → **пункты меню меняются мгновенно**, без перезагрузки.
- [ ] Пройти по всем разделам меню (Студенты / Результаты тестов / Ситуационные задачи / Контент / Назначение предметов / Пользователи — по своей роли) в обоих языках: заголовки, кнопки, таблицы, модалки — нигде не должно остаться "залипшего" узбекского текста при выбранном русском (и наоборот).

## 7. Админка — контент (Content)

- [ ] Создать/отредактировать раздел (юнит) — форма сохраняет.
- [ ] Создать/отредактировать урок.
- [ ] Открыть вкладку "Тест" у урока с вопросами → список вопросов **на всю ширину**, клик по вопросу открывает **модальное окно редактирования** (не узкая боковая панель, как было раньше) — проверить, что в модалке видно текст вопроса и все варианты ответов без утеснения.
- [ ] В модалке отредактировать текст вопроса/варианта, сохранить → изменения применились.
- [ ] Добавить новый вопрос через "Добавить вопрос" — форма достаточно широкая (760px), поле текста вопроса — многострочное.
- [ ] Импорт вопросов через Excel-шаблон ("Шаблон" → скачать → заполнить → "Импорт") — хотя бы дымовой тест на существующем шаблоне.
- [ ] Вкладка "Ситуационные задачи" — создать/отредактировать задачу, загрузить/удалить фото.
- [ ] Вкладка "Теория" — добавить материал с файлом, скачать обратно.

## 8. Админка — студенты и поиск

- [ ] Открыть "Студенты" → список загружается, есть пагинация.
- [ ] Найти студента по кириллическому ФИО — находит.
- [ ] Найти того же студента, набрав имя **латиницей** (например `Ahror` вместо `Ахрор`) — тоже находит (это был отдельный фикс на h/x путаницу).
- [ ] Отредактировать карточку студента (курс/группа/подгруппа) — сохраняется.
- [ ] Открыть результаты конкретного студента — видно тесты/задачи.

## 9. Админка — результаты тестов

- [ ] Открыть "Результаты тестов", выбрать раздел → урок → тест — фильтры (включая названия в выпадающих списках) на текущем языке интерфейса.
- [ ] Вкладка групповой статистики: проценты сдал/не сдал по группам, студенты с таймаутом **не учитываются** ни в числителе, ни в знаменателе.
- [ ] Экспорт в PDF → открывается печатная форма, в ней **не только сводная таблица по группам, но и пофамильный список** сдал/не сдал по каждому студенту.
- [ ] Открыть детализацию одного результата — текст вопроса/ответа/правильного ответа виден полностью, не обрезан.

## 10. Админка — ситуационные задачи (результаты)

- [ ] Открыть "Ситуационные задачи" → список ответов студентов, статусы (оценено/на проверке).
- [ ] Открыть один ответ → видно текст задачи, ответ студента, оценку и фидбек ИИ, источники.
- [ ] Оценить/переоценить вручную (если такая возможность есть) — сохраняется.

## 11. Админка — роли и назначение предметов

- [ ] Открыть "Назначение предметов" (доступно `ZAV_KAFEDRA`/`SUPER_ADMIN`) → список профессоров.
- [ ] Назначить профессора на один юнит (например F2) → он появляется в списке назначений этого профессора.
- [ ] Снять назначение — исчезает из списка.
- [ ] **Проверка реального ограничения прав** (не только UI): зайти под аккаунтом с ролью `PROFESSOR`, назначенным только на F2:
  - [ ] Может открыть/редактировать контент **F2** — сохраняется без ошибок.
  - [ ] Пытается редактировать урок/тест в **F1** (не назначен) → сервер отвечает **403**, а не молча позволяет.
  - [ ] Пункт меню "Контент" виден профессору (доступ по роли есть), но реальное редактирование чужого юнита блокируется именно на бэкенде, не только скрытием кнопки.

## 12. Админка — пользователи

- [ ] (`SUPER_ADMIN`) Создать нового admin-пользователя с ролью `PROFESSOR` — можно сразу войти под ним.
- [ ] Сменить пароль существующему пользователю.
- [ ] Попытаться удалить единственного `SUPER_ADMIN` — система не даёт (иначе можно остаться без доступа).

## 13. Инфраструктура / безопасность (быстрая проверка)

- [ ] С любого устройства **вне** SSH-туннеля: `curl -I http://<IP_сервера>:8080` — соединение не устанавливается (таймаут), панель недоступна напрямую из интернета.
- [ ] Через туннель `ssh dental` панель по-прежнему открывается как обычно.
- [ ] `ssh dental "systemctl is-active fail2ban ufw"` — оба `active`.
- [ ] Свежий бэкап есть: `ssh dental "ls -la /opt/dental/backups/ | tail -3"` — файл не старше суток (после первого прогона по крону в 3:00).
